# 🍠 小红书文案批量生成器

一个纯前端（HTML + CSS + JavaScript）的单页面小工具：选择行业，输入主题、目标人群、关键词和语气风格，一次批量生成 1–20 篇小红书笔记文案，并配好**封面图**和**配图建议**。

- 不需要安装任何东西，**双击 `index.html` 就能用**
- 可以一键部署到 **GitHub Pages**
- 没有后端，所有数据（包括 API Key、历史记录）**只保存在你自己的浏览器里**

## 🚀 怎么打开使用

### 方式一：本地直接打开（最简单）

1. 下载本仓库：点击 GitHub 页面上的绿色 **Code** 按钮 → **Download ZIP**，解压。
2. 双击 `index.html`，用 Chrome / Edge / Safari 等浏览器打开即可。

### 方式二：在线使用

部署到 GitHub Pages 后（见下文），直接访问 `https://你的用户名.github.io/xhs-copy-generator/`，手机上也可以打开，还能「添加到主屏幕」。

### 使用步骤

1. 选择 **行业**（以及细分方向，选「不限」则每篇随机一个方向），填写 **主题/产品**（必填），以及目标人群、关键词（输入后按回车或逗号添加，可以加多个）。
2. 选择 **语气风格** 和 **生成数量**。
3. 选择 **生成模式**：
   - **模板模式**：直接点「开始生成」，马上出结果。
   - **AI 模式**：第一次使用需要先在右上角「⚙️ 设置」里填写 API Key（见下一节）。
4. 生成后，点每篇右上角的「📋 一键复制」，粘贴到小红书即可；或者点顶部的「CSV / TXT」把全部文案导出。
5. 每篇下方有 **封面** 和 **配图建议**（见下一节）。
6. 右上角「🕘 历史」可以找回之前生成的内容。

## 🎨 一键生成小红书封面

每篇文案下方都有一张封面缩略图和 2–3 组封面大字。点击缩略图或「🎨 生成 / 下载封面」打开封面编辑器：

1. **选封面大字**：点选一组，主标题、副标题也可以直接修改（主标题里按回车可以手动换行）；还可以改左上角的角标，或者留空。
2. **选配色**：小红书红、奶油白、黑金、海洋蓝、森系绿。
3. **选排版**：居中大字、底部卡片、杂志风、顶部标题、贴纸风。
4. **上传照片做背景**（可选）：点「📷 上传照片」选择手机或电脑里的照片，可以调缩放和左右、上下位置。**照片只在你的浏览器里处理，不会上传到任何地方。**
5. 点「⬇️ 下载 PNG」，得到 1080×1440 的 3:4 竖版封面图。手机上如果下载不方便，可以直接**长按预览图保存**。

> 封面完全由浏览器 Canvas 绘制，不需要任何外部服务。封面样式和上传的照片只保留在当前页面，刷新后需要重新选择。

## 📷 配图建议

展开每篇下方的「📷 配图建议」：

- **建议拍摄的真实照片**：3–6 条拍摄清单（拍什么、什么角度和光线），照着用手机拍就行，真实照片在小红书上更容易获得信任。
- **AI 生图提示词**：每组都有中文和英文两个版本，点「复制」即可。
  - 中文提示词：粘贴到 **即梦、豆包** 等国内工具。
  - 英文提示词：粘贴到 **Midjourney**，末尾已经带了 `--ar 3:4`（竖版比例）。

> 小提示：AI 图片适合做氛围图、示意图；涉及真实产品、真实案例的内容，建议用自己拍的照片，并遵守平台对 AI 生成内容的标注要求。

> 💡 小建议：模板模式生成的是“骨架”，适合拿来改；AI 模式质量更高，会结合你的主题写出更贴切的内容。两种模式都建议发布前自己再读一遍，加上真实细节和照片。

## 🔑 怎么申请和填写 Anthropic API Key（AI 模式需要）

### 1. 申请 API Key

1. 打开 Anthropic 控制台：<https://console.anthropic.com/>，用邮箱注册并登录。
2. 进入 **Billing（账单）** 页面，绑定支付方式并充值少量额度（API 按用量计费，和 Claude 网页版会员是分开的）。
3. 打开 **API Keys** 页面：<https://console.anthropic.com/settings/keys>，点击 **Create Key**，起个名字（如 `xhs-tool`）。
4. 复制生成的 Key（以 `sk-ant-` 开头）。**Key 只显示一次**，请妥善保存。

> 费用参考：每生成一篇大约消耗几千个 token。具体价格请以 Anthropic 官网定价为准；想省钱可以在设置中选择 Sonnet 或 Haiku 模型。建议在控制台为这个 Key 设置用量上限。

### 2. 在工具里填写

1. 点击页面右上角 **⚙️ 设置**。
2. 把 Key 粘贴到「Anthropic API Key」输入框。
3. 选择模型（默认 Claude Opus 5.5，质量最好；Sonnet 5.5 更快更省；Haiku 5.5 最便宜）和并发数（默认 2）。
4. 可以先点 **测试连接**，看到「✅ 连接成功」后点 **保存**。
5. 回到主界面，选择「✨ AI 模式」，点「开始生成」。

### 🔒 关于 Key 的安全

- Key **只保存在你当前浏览器的 localStorage** 中，本工具**没有任何后端服务器**。
- 生成时，浏览器会把 Key **直接**发送到 Anthropic 官方接口 `https://api.anthropic.com`，**不会上传到本站、GitHub 或任何第三方**。代码全部公开在 `app.js`，可以自行检查。
- 在公共电脑或别人的设备上使用后，请到设置里点 **清除 Key**。
- 不要把带有 Key 的截图发给别人；如果怀疑泄露，到 Anthropic 控制台删除该 Key 重新生成即可。

### 常见问题

| 提示 | 原因与解决 |
| --- | --- |
| 网络连接失败 | 当前网络无法访问 `api.anthropic.com`，请检查网络环境 |
| API Key 无效 | Key 复制不完整或已被删除，重新复制粘贴 |
| 账户余额不足 | 到控制台 Billing 页面充值 |
| 请求太频繁（限流） | 工具会自动等待重试；也可以把并发数调成 1 |
| 模型不存在或不可用 | 在设置里换一个模型试试 |

## 🌐 怎么部署到 GitHub Pages

本项目是纯静态网页，不需要任何构建步骤。

1. **Fork 或上传代码**：把本仓库 Fork 到你自己的 GitHub 账号（或新建仓库，上传 `index.html`、`style.css`、`app.js`、`industries.js`、`templates.js`、`cover.js` 六个文件）。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 下：
   - **Source** 选 **Deploy from a branch**
   - **Branch** 选 `main`（或你的默认分支），目录选 `/ (root)`，点击 **Save**。
4. 等待 1–2 分钟，页面顶部会显示网址，一般是：
   `https://你的用户名.github.io/仓库名/`
5. 以后修改代码并推送到该分支，网站会自动更新。

> 部署后网页是公开的，但每个访问者的 API Key 和历史记录都只存在**他们自己的浏览器**里，互不影响，你的 Key 不会被别人看到。

## 📁 文件结构

```
xhs-copy-generator/
├── index.html      # 页面结构
├── style.css       # 样式（小红书红白配色，响应式）
├── app.js          # 主逻辑：表单、行业选择、Claude API 调用、封面编辑器、复制导出、历史记录
├── industries.js   # 行业数据：专业词汇、标题公式、段落模板、话题标签、封面大字、拍摄清单、生图提示词
├── templates.js    # 模板模式的生成逻辑（通用模板 + 行业模板组合）
├── cover.js        # 封面绘制（Canvas，5 种配色 × 5 种排版）
└── README.md
```

### 想扩充或修改行业模板？

直接编辑 `industries.js`。每个行业包含：

- `ai`：AI 模式下附加给 Claude 的行业背景和专业要求
- `titles` / `openers` / `summaries`：按四种语气分组的标题公式、开头、总结
- `ctas`、`tags`、`coverMain`、`coverSub`：互动引导、行业话题标签、封面主/副标题公式
- `subs`：细分方向，每个细分有 `terms`（专业词汇）、`facts`（干货知识段落）、`pitfalls`（避坑段落）、`highlights`（种草/体验段落）、`tags`、`shots`（拍摄清单）、`scenes`（中英文生图场景）

占位符：`{t}` 主题、`{p}` 人群、`{s}` 细分简称、`{c}` 洛杉矶城市/区域、`{k}` / `{k2}` 关键词、`{term}` 行业专业词、`{n}` 正文要点数（自动和正文段落数一致）。

「通用」行业的模板在 `templates.js` 里的 `TITLE_FORMULAS`、`OPENERS`、`POINTS`、`SUMMARIES`、`CTAS`、`GENERIC_TAGS`。
