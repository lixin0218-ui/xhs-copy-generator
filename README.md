# 🍠 小红书文案批量生成器

一个纯前端（HTML + CSS + JavaScript）的单页面小工具：输入主题、目标人群、关键词和语气风格，一次批量生成 1–20 篇小红书笔记文案。

- 不需要安装任何东西，**双击 `index.html` 就能用**
- 可以一键部署到 **GitHub Pages**
- 没有后端，所有数据（包括 API Key、历史记录）**只保存在你自己的浏览器里**

---

## ✨ 功能一览

| 功能 | 说明 |
| --- | --- |
| 账号人设 | **通用 / 🚪 选门新号 / 🤿 潜水老号**。选了人设，AI 模式会自动带上这个账号的定位、门类范围和红线规则（和「小红书内容助手」Skill 一致），并预填目标人群和关键词 |
| 输入区 | 主题/产品（如「潜水面镜怎么选」「入户门怎么选」）、目标人群、多个关键词、语气风格（干货科普 / 种草分享 / 避坑提醒 / 真实体验）、生成数量 1–20 篇 |
| 每篇输出 | 3 个备选爆款标题（20 字以内，可带 emoji，显示字数）、300–600 字正文（分段、emoji、口语化）、结尾互动引导、5–10 个话题标签；AI 模式还会给出**封面主/副标题和构图、6–9 张配图清单、置顶评论** |
| ✅ 合规自检 | 每篇自动检查：广告法极限词、微信/电话/网址等站外联系方式、标题超 20 字、写了价格却没写“仅供参考”。选门新号还会检查“持牌/licensed”“我来装”和合作方品牌名；潜水老号会检查“不用考证”之类的说法。只在本机运行，不调用 API |
| 🧩 模板模式 | **不需要 API Key**。用内置的标题公式和段落模板随机组合生成，秒出结果，适合找灵感 |
| ✨ AI 模式 | 填入你自己的 Anthropic API Key，调用 Claude 批量生成。可选模型和并发数，显示实时进度，支持中途停止，失败自动重试 |
| 复制 | 每篇都有「一键复制」（标题+正文+互动引导+标签），也可单独复制某个标题 |
| 导出 | 全部导出为 **CSV**（Excel 直接打开不乱码）、**TXT** 或 **JSON**（字段：industry、title、cover_text、body、hashtags、image_notes 等，和 Skill 的批量模式一致） |
| 历史记录 | 每次生成自动保存到浏览器 localStorage（最多 50 次），可查看、删除、清空 |
| 适配 | 中文界面，小红书红白配色，手机和电脑都能用 |

## 🚀 怎么打开使用

### 方式一：本地直接打开（最简单）

1. 下载本仓库：点击 GitHub 页面上的绿色 **Code** 按钮 → **Download ZIP**，解压。
2. 双击 `index.html`，用 Chrome / Edge / Safari 等浏览器打开即可。

### 方式二：在线使用

部署到 GitHub Pages 后（见下文），直接访问 `https://你的用户名.github.io/xhs-copy-generator/`，手机上也可以打开，还能「添加到主屏幕」。

### 使用步骤

1. 填写 **主题/产品**（必填），以及目标人群、关键词（输入后按回车或逗号添加，可以加多个）。
2. 选择 **语气风格** 和 **生成数量**。
3. 选择 **生成模式**：
   - **模板模式**：直接点「开始生成」，马上出结果。
   - **AI 模式**：第一次使用需要先在右上角「⚙️ 设置」里填写 API Key（见下一节）。
4. 生成后，点每篇右上角的「📋 一键复制」，粘贴到小红书即可；或者点顶部的「CSV / TXT」把全部文案导出。
5. 右上角「🕘 历史」可以找回之前生成的内容。

> 💡 小建议：模板模式生成的是“骨架”，适合拿来改；AI 模式质量更高，但同样建议发布前自己再读一遍、加上真实细节和图片。

## 🔑 怎么申请和填写 Anthropic API Key（AI 模式需要）

### 1. 申请 API Key

1. 打开 Anthropic 控制台：<https://console.anthropic.com/>，用邮箱注册并登录。
2. 进入 **Billing（账单）** 页面，绑定支付方式并充值少量额度（API 按用量计费，和 Claude 网页版会员是分开的）。
3. 打开 **API Keys** 页面：<https://console.anthropic.com/settings/keys>，点击 **Create Key**，起个名字（如 `xhs-tool`）。
4. 复制生成的 Key（以 `sk-ant-` 开头）。**Key 只显示一次**，请妥善保存。

> 费用参考：每生成一篇大约消耗几千个 token。具体价格请以 Anthropic 官网定价为准；想省钱可以在设置中选择 Sonnet 或 Haiku 模型。建议在控制台为这个 Key 设置用量上限。

### 2. 在工具里填写

1. 点击页面右上角 **⚙️ 设置**。
2. 把 Key 粘贴到「Anthropic API Key」输入框。
3. 选择模型（默认 Claude Opus 5.5，质量最好；Sonnet 5.5 更快更省；Haiku 5.5 最便宜）和并发数（默认 2）。
4. 可以先点 **测试连接**，看到「✅ 连接成功」后点 **保存**。
5. 回到主界面，选择「✨ AI 模式」，点「开始生成」。

### 🔒 关于 Key 的安全

- Key **只保存在你当前浏览器的 localStorage** 中，本工具**没有任何后端服务器**。
- 生成时，浏览器会把 Key **直接**发送到 Anthropic 官方接口 `https://api.anthropic.com`，**不会上传到本站、GitHub 或任何第三方**。代码全部公开在 `app.js`，可以自行检查。
- 在公共电脑或别人的设备上使用后，请到设置里点 **清除 Key**。
- 不要把带有 Key 的截图发给别人；如果怀疑泄露，到 Anthropic 控制台删除该 Key 重新生成即可。

### 常见问题

| 提示 | 原因与解决 |
| --- | --- |
| 网络连接失败 | 当前网络无法访问 `api.anthropic.com`，请检查网络环境 |
| API Key 无效 | Key 复制不完整或已被删除，重新复制粘贴 |
| 账户余额不足 | 到控制台 Billing 页面充值 |
| 请求太频繁（限流） | 工具会自动等待重试；也可以把并发数调成 1 |
| 模型不存在或不可用 | 在设置里换一个模型试试 |

## 🌐 怎么部署到 GitHub Pages

本项目是纯静态网页，不需要任何构建步骤。

1. **Fork 或上传代码**：把本仓库 Fork 到你自己的 GitHub 账号（或新建仓库，上传 `index.html`、`style.css`、`app.js`、`presets.js`、`templates.js` 五个文件）。
2. 打开仓库的 **Settings → Pages**。
3. 在 **Build and deployment** 下：
   - **Source** 选 **Deploy from a branch**
   - **Branch** 选 `main`（或你的默认分支），目录选 `/ (root)`，点击 **Save**。
4. 等待 1–2 分钟，页面顶部会显示网址，一般是：
   `https://你的用户名.github.io/仓库名/`
5. 以后修改代码并推送到该分支，网站会自动更新。

> 部署后网页是公开的，但每个访问者的 API Key 和历史记录都只存在**他们自己的浏览器**里，互不影响，你的 Key 不会被别人看到。

## 📁 文件结构

```
xhs-copy-generator/
├── index.html     # 页面结构
├── style.css      # 样式（小红书红白配色，响应式）
├── app.js         # 主逻辑：表单、Claude API 调用、合规自检、复制导出、历史记录
├── presets.js     # 账号人设：通用 / 选门新号 / 潜水老号（人设规则、默认人群、标签、自检规则）
├── templates.js   # 模板模式：标题公式 + 段落模板
└── README.md
```

想改账号人设？编辑 `presets.js`：`system` 是追加给 AI 的人设和规则，`audience` / `keywords` 是预填内容，`tags` 是模板模式用的标签，`checks` 是额外的自检规则（规则本身在 `app.js` 的 `CHECK_RULES`）。以后选门账号扩展到车库门、卷帘门时，改 `presets.js` 里的门类范围就行。

想扩充模板？直接编辑 `templates.js` 里的 `TITLE_FORMULAS`（标题公式）、`OPENERS`（开头）、`POINTS`（正文要点）、`SUMMARIES`（总结）、`CTAS`（互动引导）、`GENERIC_TAGS`（通用标签）即可。占位符：`{t}` 主题、`{p}` 人群、`{k}` / `{k2}` 关键词、`{n}` 随机数字。
